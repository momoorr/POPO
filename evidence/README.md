| 증거 ID | 연결 요구사항/테스트 | 실행 ID | 출처·수집일 | 공개 가능한 파일 | 검증 결과 |
|---|---|---|---|---|---|

## 저장 정책

- 동의받은 공개 가능 자료만 `evidence/`에 넣습니다.
- 원본 출생 정보·인터뷰 녹취·상담 세션·API 키는 GitHub에 올리지 않습니다.
- 공개본 이미지는 식별 정보를 제거하고, 실행 ID/기능 버전/날짜를 표시합니다.
- 동일 입력의 수정 전후 결과는 별도 파일로 보관하고 이전 실패 증거를 지우지 않습니다.

# Stage 5C — 사용자의 실제 Supabase 실사용 QA

- [ ] 최신 POPO 로컬 웹 접속 -> 카카오 로그인 상태 확인 -> 오른쪽 상단 마이페이지.
- [ ] `+ 내 사주 입력하기`를 눌렀을 때 **기존 계산 시험창이 아닌 사주 보관함**이 나타남.
- [ ] 가상의 이름/날짜/시간/관계/성별/지역 입력 -> 저장 -> 보관함 목록에 표시.
- [ ] 팝업 닫고 새로고침 -> 같은 계정에서 마이페이지 -> 목록이 그대로 유지됨.
- [ ] 수정 -> 새로고침 -> 새 이름 또는 설정 반영.
- [ ] 출생 시간 모름 체크 -> 저장 -> 수정에서 시간 입력칸이 비활성화되고 값은 비어 있음.
- [ ] 기타 관계 선택 -> 직접 입력 필수 확인.
- [ ] 삭제 버튼 -> 취소 시 유지, 확인 시 삭제 -> 새로고침해도 삭제 유지.
- [ ] 로그아웃 시 사주 보관함이 닫히고, 비회원은 저장 목록 접근 불가능.
- [ ] 계정 B로 로그인 시 A의 저장 목록 및 ID로 직접 SELECT/UPDATE/DELETE 차단 (RLS 실측). 개인정보와 키를 채팅에 보내지 말 것.
- [ ] 작은 스마트폰(360/390px)에서 가로 넘침·버튼 터치 문제 없음.

**테스트에 실제 개인 생년월일 대신 가상 정보를 사용.**
실제 카카오 Auth/RLS 검증 전에는 전체 서비스 완료라고 부르지 않음.

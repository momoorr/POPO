# 사용자 실사용 QA (실행 결과는 사용자가 확인 전)

- [ ] 마이페이지 → 새 사주 등록 → 태어난 시간. 오전/오후 → 시 → 분을 누르면 자동으로 닫힘.
- [ ] 취소/X/Esc는 시간 값 변경 없이 입력폼으로 복귀. ‘시간 모름’ 체크가 저절로 바뀌지 않음.
- [ ] 오전 12시=00시, 오후 12시=12시 저장. 00~59분 선택 가능.
- [ ] 저장 성공 후 포포 마이페이지로 복귀. 이름·관계·양음력·날짜·시간·지역 표시.
- [ ] 보관함 X/완료/Esc → 마이페이지. 마이페이지 X만 사이트로 닫힘.
- [ ] 저장 실패 시 입력 유지, 성공 메시지/자동 복귀 없음.
- [ ] 기존 기록 수정·삭제·재조회 정상. 다른 계정으로 전환하면 이전 계정 정보가 남지 않음.
- [ ] 실제 Chrome Windows, Android Chrome, iOS Safari에서 시간 선택과 카드 줄바꿈 확인.
- [ ] 캐릭터는 기본 POPO 표시. 개인 오행/새 동물 배정은 아직 연결 전이라는 개발 상태 유지.

모의 브라우저 테스트는 실제 Supabase RLS나 운영체제별 동작을 완전히 대체하지 않습니다.

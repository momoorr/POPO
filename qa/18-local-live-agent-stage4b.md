# POPO Stage 4B — 실제 AI Agent 로컬 채팅 연결 QA

- 상태: **코드 및 모의 네트워크 테스트 완료 / 사용자 로컬 브라우저 실호출 전 / GitHub 업로드 전**
- 기존 실제 API 확인(사용자 보고, 2026-11-04):
  - 일반 질문: 한국어 오행 설명, `tools_used=[]`, `chart_verified=false`, 비용 추정 `$0.0007168`
  - 개인 명식 요청: `tools_used=["get_saju_chart"]`, `chart_verified=false`, 비용 추정 `$0.002707`
  - 두 번째 답변은 출력이 중간에 끊긴 것으로 보여 품질 검증은 **보류**. 도구 미연결·검증불가 안내는 올바르게 작동함.
- Stage 4B은 웹 대화 화면 → 로컬 FastAPI `/api/chat` UI 통합을 위한 별도 작업. AI 상담 답변 품질은 자동 PASS로 간주하지 않음.

| ID | 확인 항목 | 상태 |
|---|---|---|

**개인정보 보호:** 실제 생년월일·이름·개인 사정 없이 가상 질문으로 테스트. AI 질문과 성공한 최근 6개 메시지는 API로 전송되며, 브라우저 메모리에서만 보유. 백엔드 `store=False` 유지. API 키는 프런트엔드에 저장하지 않는다.

**개발 제약:** 현재 Agent `get_saju_chart`는 명시적으로 `unavailable` 반환. Stage 4B은 검증되지 않은 원국 후보를 AI 상담에 연결하지 않는다.

# POPO 오행별 포포 5종 QA — v1.1

**기록일:** 2026-10-30  
**대상:** 오행 5종을 표시하는 로컬 코드 패치  
**테스트 방법:** Chromium 기반 Playwright 자동 검사. 로컬 웹서버와 `file://` 접근이 실행 환경에서 차단되어, HTML·CSS·JS와 로컬 이미지를 테스트 브라우저에 인라인 주입해 검증. **실제 GitHub Pages 검증과 별개**입니다.

## 3. 화면별 관찰 메모

### 3.1 궁합 입력 오류

- **입력:** 나(A) 날짜 유지, 상대방(B) 날짜 삭제 후 `가상 예시 결과 보기` 클릭
- **기대:** 입력 누락을 알리고 결과 화면에 진입하지 않음
- **관찰:** `나와 상대방의 가상 날짜를 모두 입력해 주세요.` 메시지 표시, STEP 02 유지
- **결론:** 해당 누락 사례의 차단 동작 확인. 메시지가 어떤 칸이 비었는지 특정하지 않음

### 3.2 궁합 결과와 관계 전환

- **입력:** 가상 날짜 및 연인 선택 → STEP 03 표시
- **관찰:** 시연용 안내와 `감정 표현 방식/서로 편한 점/갈등 시 반응/대화 팁` 4개 항목 노출
- **전환:** 친구 관계로 변경해 결과 표시
- **관찰:** `친해지는 방식/함께하는 강점/불편해지는 상황/관계 유지 팁` 항목으로 제목 변경
- **한계:** 현재 카드 본문은 관계 종류와 무관한 공통 예시 문구가 주로 사용됨

### 3.3 명리 용어 팝업

- **입력:** 내 사주에서 `일간` 선택
- **관찰:** 기본 설명, 심화 설명, 시연용 안내 표시
- **확인:** 심화 접기/펼치기 정상, Esc로 닫기 및 Enter로 재열기 정상(사용자 직접 확인)
- **한계:** 펼친 상태에도 버튼 텍스트가 `전문가 심화 설명 보기`로 유지됨

## 5. 증거 및 범위 관리

- **확인 근거:** 프로젝트 대화에서 공유된 사용자의 실제 UI 화면 캡처와 기능 동작 확인 메시지. 해당 원본 캡처는 아직 공개 저장소에 첨부하지 않음
- **테스트 데이터:** 가상 날짜 및 시연용 결과. 실제 관계·출생 정보를 판단하거나 저장한 테스트가 아님
- **향후 보완:** QA 항목별 비식별 캡처, 브라우저/화면 크기, 실행 일시, 재현 단계, 실제 수정 커밋과 재검증 결과를 남길 예정
- **주의:** 사용자의 문장 확인은 기능별 수동 테스트 증거로 기록했으며, 자동화 테스트·실사용자 조사 또는 배포 품질 인증으로 해석하지 않음

# Stage 5C.4 실사용 확인표

| 항목 | 정상 결과 | 사용자 계정 확인 |
|---|---|---|
| 보관함 → 수정 → 저장 | 보관함 유지, 수정된 내용 표시 | 미확인 |
| 보관함 → 새 등록 → 저장 | 보관함 유지, 목록/개수 증가 | 미확인 |
| 보관함 → 삭제 | 보관함 유지, 목록/개수 감소 | 미확인 |
| 보관함 수정 → 취소/X/Esc | 보관함으로 돌아옴, 미저장 내용 폐기 | 미확인 |
| 보관함 목록 → X | 마이페이지로 복귀, 최신 정보 표시 | 미확인 |
| 마이페이지 → 바로 등록 → 저장 | 기존처럼 마이페이지로 복귀 | 미확인 |
| 기본 화면 | 목록 새로고침·하단 완료 버튼 없음 | 미확인 |
| 일시적 목록 조회 실패 | 실패 안내 및 재시도 표시, 저장/삭제 중복 없음 | 미확인 |

모의 브라우저에서는 위 흐름과 추가 실패/계정 전환 조건을 검사했지만 실제 계정 검증을 대신하지 않는다. 실제 사주 정보 대신 가상 시험 항목으로 수정·삭제를 확인한다.

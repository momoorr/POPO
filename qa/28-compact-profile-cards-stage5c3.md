# 5C.3 사용자 QA

1. 설치 후 Ctrl+Shift+R. 보관함에서 수정/삭제가 정보 오른쪽에 표시되는지 확인한다.
2. 320px~440px 너비에서도 가로 스크롤과 잘린 글자가 없는지 확인한다. 긴 이름은 줄바꿈을 허용한다.
3. 수정/삭제 버튼의 기능이 유지되는지 가상 항목으로 확인한다. 삭제 확인창은 유지한다.
4. 하단 완료 버튼이 없는지, X/Escape가 마이페이지로 돌아가는지 확인한다.
5. 시간 선택과 저장 성공 후 마이페이지 복귀가 유지되는지 확인한다.

모의 브라우저 검사는 실제 Kakao/Supabase/Windows 검사를 대체하지 않는다. 설치 프로그램은 DB 또는 API를 호출하지 않는다.

# POPO Stage 4A — 브라우저↔로컬 FastAPI 연동 QA

**상태:** 로컬 자동 테스트 통과. 사용자 Windows/Chrome 핵심 흐름 확인, 예외 테스트 진행 전.

| ID | 시험 | 기대 결과 | 실제 상태 |
|---|---|---|---|
| L01 | `http://localhost:5500/prototype/index.html` → 내 사주 시작 | 기존 출생 정보 dialog 정상 표시 | PASS (2026-11-03, 로컬 5501) |
| L02 | 2000-01-01 / 12:00 / 양력 / 서울 → `로컬 서버로 계산 시험하기` | `己卯 / 丙子 / 戊午 / 戊午`, 오행 1/3/3/0/1 | PASS (2026-11-03, 로컬 5501) |
| L03 | 응답 표시 | `candidate_only`가 개인 사주로 승격되지 않고 `검증 전` 문구 표시 | PASS (2026-11-03, 로컬 5501) |
| L04 | 날짜 2000-01-05로 변경 후 다시 실행 | 서버 422 및 미지원 입력 메시지, 가상 계산으로 대체하지 않음 | 사용자 미실행 |
| L05 | 입력 날짜 변경 | 이전 서버 결과 즉시 초기화 | 사용자 미실행 |
| L06 | FastAPI 종료 후 시험 | 요청 실패 안내, 임의 결과 없음 | 사용자 미실행 |
| L07 | GitHub Pages에서 접속 | 로컬 QA 버튼 숨김, 공개 페이지에서 localhost 네트워크 호출 없음 | 자동 확인/브라우저 추가 필요 |
| L08 | 기존 가상 명식·로컬 브라우저 후보·궁합·용어·오행 | 기존 동작 보존 | 사용자 미실행 |

**정책:** 로컬 서버와 GitHub Pages는 별개의 실행 환경. API 키는 프런트엔드에 넣지 않고 실제 개인 출생정보는 시험에 쓰지 않음. 기존 계산값은 전체 한국 만세력 검증 전이므로 `verified:false`, `can_personalize:false` 유지.

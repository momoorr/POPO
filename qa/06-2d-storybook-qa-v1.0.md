# 포포(POPO) 2D 랜딩·오행 UI QA 기록 v1.0

**2026-10-30 작성 · 배포 전 검사**

## 실제 수행한 기술 점검

| 항목 | 검사 방식 | 결과 | 한계 |
|---|---|---|---|
| JS 구문 | `node --check prototype/app.js` | PASS | 런타임 브라우저 동작 보장 아님 |
| 화면·버튼 연결 | 정적 HTML 파싱(고유 ID, view 참조 확인) | PASS | 실사용 클릭 검증 전 |
| SVG 자산 | 5개 SVG XML 파싱 | PASS | 브라우저별 렌더링 검증 전 |
| 이미지 경로 | 신규 파일 경로 및 승인된 기존 토끼 자산 참조 확인 | PASS(구조) | GitHub Pages 실제 로드 확인 전 |
| 오행 상태관리 | Node VM 격리 테스트(연속 선택, 선택 상태, 풍경 1개 활성) | PASS | 통합 브라우저 테스트 아님 |
| 키보드 로직 | Node VM 격리 테스트(화살표/Home/End, 포커스 이동) | PASS | 실제 포커스 UI 수동 검증 전 |
| 모션 감소 | `prefers-reduced-motion` CSS 존재 확인 | PASS(정적) | 실제 OS 설정에서 동작 확인 전 |

**한계:** 이 실행 환경에서는 Chromium이 로컬·localhost 페이지 로딩을 차단하여 통합 브라우저 자동 테스트를 완료하지 못했다. 브라우저 테스트 PASS로 기록하지 않는다.

### 결과 기입 규칙

테스트 완료 시 `실행일/환경/결과(PASS·FAIL)/실제 행동/스크린샷 또는 링크/문제·수정/재검증`을 기록한다. 실제 실행 전에 수치나 결과를 채우지 않는다.

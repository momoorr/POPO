## 포지셔닝 판단

단순히 `AI 사주`, `귀여운 캐릭터`, `쉬운 풀이`, `운세 종류가 다양함`만 강조하면 경쟁사와 겹친다. 실제로 포스텔러는 전통 운세에 현대적 캐릭터와 쉬운 해석을 활용해 온 서비스이므로, 해당 요소가 포포만의 독점적인 차별화라고 주장하지 않는다.

**우리가 실험할 경험:**
1. 처음엔 2~3문장 핵심과 연관된 명식 요소만 표시.
2. 원하면 전문적인 해석 근거를 펼침.
3. 같은 데이터를 들고 현재 주제에서 AI 후속 상담을 시작.
4. 동일한 연운 데이터를 초보자용/전문가용 표현으로 제공.
5. 연도별 사주 해석과 토정비결이 **다른 방식**임을 명시.

이는 **차별화 가설**이지 경쟁 서비스에 없는 기능이 입증되었다는 뜻이 아니다.

## 실제 앱 비교 때 기록할 항목

- 신규 사용자 입력 단계 수/오류 상태/시간 미상 처리
- 명식 결과 첫 화면의 정보량, 한자/한글 표기
- 풀이 카테고리 찾기까지 걸린 클릭 수
- 근거 노출 위치/심화 정보 구조
- AI 대화에서 명식·카테고리 문맥이 이어지는지
- 캐릭터의 시각적 메타포/개인정보 공유 방식
- 서비스의 유료 벽 및 약관/개인정보 흐름

비교 시 반드시 **날짜, 앱 버전, 화면 스크린샷, 직접 수행한 동작**을 기록한다. 타사 삽화나 화면을 그대로 디자인 자산으로 사용하지 않는다.

# POPO 오행별 캐릭터 콘텐츠-비주얼 연동 v1.1

> 작성: 2026-10-30 · 목적: 서비스기획 포트폴리오의 UI 개선 근거 기록
> 상태: 5종 이미지와 UI 연결 코드 제작. 실제 공개 사이트 수동 검증은 배포 후 수행.

## 1. 발견한 문제

v1.0 오행 화면은 배경·텍스트가 바뀌지만 캐릭터는 다섯 화면에 동일한 둥근 이미지를 반복 표시했습니다. 사용자가 각 오행의 상징을 **풍경과 캐릭터의 행동**으로 함께 이해하기 어렵다는 UX 문제를 발견했습니다(사용자 직접 피드백, 정량 검증 전).

## 2. 개선 의사결정

- 기존 승인된 달토끼 포포의 흰색 몸·분홍 귀와 볼·순한 눈매를 유지합니다.
- 다섯 오행별로 다른 동작/소품을 제공합니다.
- 기존 2D 풍경·설명 데이터·탭 키보드 제어·궁합·명리 용어 팝업을 유지합니다.
- 이미지가 원형 액자에 보이는 문제를 해결하기 위해 캐릭터를 무테의 풍경 일러스트로 배치합니다.

| 오행 | 캐릭터의 모습 | 풍경 | UX 의미(전통적 상징의 예시) |
|---|---|---|---|
| 목(木) | 새싹 화분을 품은 포포 | 작은 숲 | 성장·뻗어감 |
| 화(火) | 빛나는 별을 만지는 포포 | 노을과 따뜻한 불빛 | 열기·발산 |
| 토(土) | 흙과 씨앗을 안은 포포 | 포근한 언덕 | 바탕·안정 |
| 금(金) | 두 손으로 수정을 든 포포 | 은빛 결정 | 선명함·단단함 |
| 수(水) | 물 위에서 쉬는 포포 | 달빛 호수 | 흐름·깊이 |

## 3. 변경 파일

- `prototype/index.html`: 각 오행별 이미지 5종 삽입, 기존 원형 동일 이미지 제거
- `prototype/styles.css`: 2D 그림의 자연스러운 배치와 투명도 전환, 반응형, reduced-motion
- `prototype/app.js`: 선택된 오행에 맞춰 2D 배경·포포·텍스트·접근성 레이블을 동시에 전환
- `prototype/assets/five-elements/popo-{wood,fire,earth,metal,water}.webp`: 오행별 자체 제작 캐릭터 일러스트

추가 모델이나 사주 계산 API 도입은 없습니다. 실제 오행 비율이나 개인 성격을 산출하는 기능이 아니며 **일반 개념 탐색용 시연**입니다.

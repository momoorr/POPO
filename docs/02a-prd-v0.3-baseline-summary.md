# PRD v0.3 제품 기준선 요약 · 2026.10.29

> 본 문서는 사용자가 제공한 「포포 프로젝트 통합 마스터 프롬프트 v0.3」와 그에 따른 확정 방향을 GitHub 열람용으로 요약한 것입니다. 이전 PRD v0.2 원문 전체 및 과거 SCR-01~05 화면설계서 원본은 이 저장소에 확보되지 않았습니다. 따라서 **원본 문서 전체를 재현하거나 문장별 변경 이력을 확인했다는 뜻이 아닙니다.**

## 제품 정의

**포포**은 사주 명식을 계산하고 쉬운 설명·전문가 심화 해석 및 명식 근거를 통해 AI 후속 상담으로 연결하는 한국어 B2C 모바일 우선 서비스입니다. 명리학과 타로를 사실 예측의 과학적 방법으로 제시하지 않습니다.

## 확정 제품 의사결정

| ID | 기준 |
|---|---|
| D-01 | 쉬운 설명을 기본으로, 전문가 심화 보기 선택 가능. 동일 명식 데이터 참조 |
| D-02 | 출생정보 입력 후 명식 결과 먼저 노출, 이후 풀이와 AI 상담 진입 |
| D-03 | 비회원 기본 체험 허용, 선택 회원가입 및 기록 정책은 미결정 |
| D-04 | AI 상담의 차분하고 따뜻한 말투, 질문에 먼저 답하고 근거 제공 |
| D-05 | 명식 계산은 별도 역법 모듈, AI는 구조화된 계산 결과에 기반한 해석만 수행 |
| D-06 | P0 핵심 경험 우선, P1 캐릭터/운세/타로/회원, P2 장기 운세/궁합 |

## 기능 범위

### P0 — 핵심 MVP

홈, 출생정보 입력(양·음력/윤달/시간 모름/지역), 원국 계산, 명식 결과, 카테고리형 쉬운 풀이, 전문가 심화 보기, AI 후속 상담, 비회원 체험, 계산 불확실성 안내.

### P1 — 핵심 확장

60갑자 일주 캐릭터, 오늘의 운세, 타로 기본 기능, 선택적 회원가입 및 상담 기록. **캐릭터 60종 디자인 및 기능은 아직 미완료.**

### P2 — 후속 확장

월간·연간 운세, 궁합, 대운 등 시기별 분석과 고급 개인화.

## 화면 IDs

- SCR-01: 홈
- SCR-02: 출생정보 입력
- SCR-03: 명식 결과
- SCR-04: 기본·심화 해석
- SCR-05: AI 사주 상담
- SCR-06~09: 오늘의 운세 / 캐릭터 / 타로 / 계정·기록 (P1)
- SCR-10~11: 시기별 운세 / 궁합 (P2)

기존 SCR-01~05의 상세 v0.1 원본은 제공되지 않았고, 현재 GitHub에는 v0.4 변경·추가 제안만 있습니다(`docs/10-screen-spec-addendum.md`). 원본 확보 시 정확한 변경표로 교체합니다.

## 요구사항 ID 개요

- `FR-001~008`: 비회원 및 출생정보 입력·검증·수정
- `FR-009~014`: 명식 산출, 천간·지지·오행, 정책·불확실성·재현성
- `FR-015~020`: 카테고리형 기본·심화 해석 및 AI 질문 연결
- `FR-021~028`: AI 상담 주제, 질문, 명식·문맥 전달, 근거와 오류 처리
- `FR-029~032`: 일주 캐릭터 (P1)
- `FR-033~036`: 오늘의 운세 (P1)
- `FR-037~041`: 타로 (P1)

세부 예외·QA·AI 정책은 각 연관 문서와 추적표를 참조합니다. `FR-V04-001~007`은 **별도의 신규 변경 제안**이며 이 기준선을 자동으로 덮어쓰지 않습니다.

## 미결정 정책

절기·자시 경계, 음력/윤달 변환, 시간·지역 보정, 출생 시간 미상 범위, 대운/세운/일운 계산, 격국·용신 학파, 회원 기록 보존·이관, 정확한 기술 스택. 이 사항을 임의로 확정하거나 역법 계산 결과를 목업에서 실제값처럼 표시하지 않습니다.

## QA·서비스 정책

- 계산값은 AI가 변경할 수 없음.
- 이전 사용자·이전 명식 문맥이 혼합되지 않아야 함.
- 계산 실패·AI 장애·보안 오류에 대한 복구 메시지와 확인 기준 필요.
- 사용성 조사·검증·성과 수치는 실제 수행한 범위만 작성.
- 개인 출생정보·상담 데이터 최소 수집 및 공개 저장소 비노출.

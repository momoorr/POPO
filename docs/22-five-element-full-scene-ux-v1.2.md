# POPO 오행 5장면 통합 UI v1.2

## 1. 개선 배경

기존 오행 화면에서는 인물 일러스트의 고유 풍경 위에 별도의 SVG 언덕·구름·하늘을 중첩해, 서로 다른 배경이 동시에 보였습니다. 사용자 화면 검토(2026-10-30)에서 해당 시각적 불일치가 발견되어 수정했습니다.

## 2. 변경 요구사항

- 목·화·토·금·수 각각 **포포와 해당 풍경이 결합된 독립 장면**을 카드 전면에 표시한다.
- 기존 `scene-*.svg` 이미지와 별도의 캐릭터 레이어를 중첩하지 않는다.
- 이미지 변경 시 현재 선택한 오행 탭, 제목, 설명, 접근성 속성도 함께 변경한다.
- 홈·명식·궁합·용어 설명·AI 시연 등 기존 기능은 변경하지 않는다.
- 장면 내용은 오행의 **전통적 상징을 표현하는 시각적 예시**이지 개인 사주 계산값이 아니다.

## 3. 파일별 변경

| 파일 | 변경사항 |
|---|---|
| `prototype/index.html` | 중첩 SVG/캐릭터 레이어를 완성 장면 5장으로 교체 |
| `prototype/styles.css` | 새 장면의 전체 카드 배치, 배지/주석 가독성, 전환 효과, 반응형 적용 |
| `prototype/assets/five-elements/popo-*-scene.webp` | 기존 포포 원본 5장의 배경을 확장해 완성형 장면 자산으로 변환 |
| `prototype/app.js` | **변경 없음**. 기존 `data-element-character` 선택 로직 재사용 |

원본 `scene-*.svg` 및 `popo-{element}.webp` 파일은 삭제하지 않았으며, 다른 곳에서 참고하거나 롤백할 수 있습니다. 실제 UI에서는 중첩 렌더링에 사용하지 않습니다.

## 4. 디자인 정책

목(숲)·화(노을)·토(언덕)·금(별과 결정)·수(달빛 호수) 장면을 각각 사용합니다. 이미지에 서비스의 텍스트 설명을 굽지 않고 HTML로 별도 제공해 접근성과 수정 편의성을 유지합니다.

이미지는 기존 5종을 재사용하되, 일러스트 가장자리의 투명 영역을 동일한 원본 풍경에서 확장해 **불투명한 WebP**로 제작했습니다. 새로운 사주 해석이나 검증되지 않은 수치를 만들지 않았습니다.

## 5. QA 및 수용 기준

- 각 오행 선택 시 해당 완성형 이미지 1개만 보이고 배경 충돌이 없어야 합니다.
- 목→화→토→금→수 전환 시 시각 자료, 설명, 선택 상태, 접근성 레이블이 일치해야 합니다.
- 모바일 360px/390px 화면에서 레이아웃이 가로로 넘치지 않아야 합니다.
- 키보드 화살표 탐색, `prefers-reduced-motion`, 기존 궁합·용어 설명 기능을 검증합니다.

자세한 QA 기록: [`../qa/08-five-element-full-scene-qa-v1.2.md`](../qa/08-five-element-full-scene-qa-v1.2.md).

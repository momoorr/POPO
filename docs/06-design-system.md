# UI 디자인 시스템 — Midnight Stardust v0.1

**상태:** 제안 및 목업 적용. 앱 전체 디자인 시스템의 최종 승인 아님.

## 한 줄 원칙

> **신비로움은 배경에, 이해하기 쉬운 정보는 전면에.**

## 색상

| 토큰 | HEX | 역할 |
|---|---|---|
| `--midnight` | `#11162F` | 신비로운 야간 배경 |
| `--deep-plum` | `#24204A` | 그라데이션·강조 배경 |
| `--lavender` | `#C6B7FF` | 주요 액션/장식 |
| `--gold` | `#E5C47A` | 별빛·프리미엄 포인트 |
| `--ivory` | `#FCF9F3` | 긴 문장·리포트 배경 |
| `--ink` | `#24253D` | 본문 글자 |
| `--muted` | `#67687C` | 보조 정보 |
| `--mint` | `#A9E5D5` | 친근한 캐릭터 포인트 |

실제 텍스트 대비는 색상·크기 조합별로 추가 테스트한다. 색상으로만 오행 의미를 전달하지 않는다.

## 컴포넌트

- **Hero**: 1문장 가치 제안 + 1개의 주 CTA + 작은 별 패턴
- **Birth form**: 양/음력·생년월일·시간 모름·지역·윤달. 순차 안내와 즉시 오류
- **Chart card**: 4주 카드(미상 시주 제외), 표시 기준 및 설명 툴팁
- **Topic tile**: 아이콘+짧은 이름+한 줄 설명; 한 행 2개/가로폭에 따라 1개
- **Reading card**: 첫 문장 요약 → 근거 뱃지 → '자세히' → 'AI에 질문'
- **Character card**: 큰 캐릭터 + 일주명 + 공유 시 개인정보 제외
- **AI chat**: 사용 질문 강조, 근거 펼침, 출처/한계 분리
- **Loading/error**: 콘텐츠 뼈대 및 복구 CTA

## UX 원칙

1. 1화면 1개의 주요 행동. 호기심보다 길 찾기가 우선.
2. 해석 콘텐츠는 60~90자 내 요약 + 펼쳐보기(숫자는 UI 작성 목표, 미검증).
3. 기분을 표현하는 반짝임은 장식 영역에서만 사용. 본문 뒤 애니메이션 금지.
4. 움직임 줄이기(`prefers-reduced-motion`) 존중. 움직이는 별은 기본적으로 매우 느리거나 정지.
5. 고령 사용자도 쓸 수 있도록 터치 면적·글자 크기·명확한 레이블 확보.
6. 한자와 용어에는 쉬운 풀이. 근거/단순 상징/사실 구분.
7. 혼란 방지: 대운·세운·올해 총운·토정비결의 차이를 안내.
8. 실제 계산/미구현/예시 문구는 UI에서도 명확히 표시.

## 시안 구현 현황

`prototype/` 디렉터리에서 모바일과 데스크톱 반응형 **클릭 가능한 목업** 제공. 검증된 명식 계산과 AI 호출은 없음.

# GitHub 공개 전 점검표

- [ ] 공개 계정과 저장소 소유자가 본인인지 확인한다.
- [ ] 공개 저장소의 `README`가 실제 완료 범위를 과장하지 않는다.
- [ ] 실제 사용자 출생 정보·상담 내용·인터뷰 녹취는 공개하지 않는다.
- [ ] API 키, 토큰, `.env`, 개인키, 내부 계정, 서버 주소를 커밋하지 않는다.
- [ ] AI 출력·브라우저 로그·스크린샷에 개인정보가 남아 있지 않다.
- [ ] 경쟁사 화면·캐릭터·문구·원문은 무단 복제하지 않는다.
- [ ] 토정비결 원문/현대어 번역·캐릭터·폰트의 이용권한을 확인한다.
- [ ] 외부 스크립트/서비스 의존성 및 개인정보 전송 여부를 확인한다.
- [ ] 공개되는 이미지·PPT에 개인 연락처, 회사 내부 자료, 다른 팀원의 개인정보가 없다.
- [ ] 링크와 정적 목업을 브라우저에서 확인한다.
- [ ] 사용자 조사 결과는 실제 수행한 날짜·방법·표본과 함께만 공개한다.
- [ ] 업로드 전 Git 상태 확인(`git status`, `git diff --cached --stat`)을 마쳤다.

**주의:** 첨부된 ALEPH 보안 캡스톤 가이드는 포포의 공식 평가 기준이 아니므로 원본 PDF를 이 저장소에 재게시하지 않습니다. 학습한 기록 방법만 별도 문서에 요약합니다.

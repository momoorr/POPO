# POPO Stage 4G — 달빛 계정 진입점 + 스크롤 플로팅 메뉴

## 배경 및 결정

- 사용자 벤치마크: `https://saju-kid.com/` 및 `https://ppippi.me/`의 모바일 중심 화면과 상단 로그인 진입점.
- 사용자 요청: 440px 모바일 단일 레이아웃 유지, **화면 하단 고정 4칸 메뉴 제거**, 스크롤 중 언제든 눌러 이동할 수 있는 버튼으로 교체.
- 디자인 결정: POPO의 달토끼 세계관에 맞춰 우측 상단 **초승달 + 작은 별** 계정 아이콘. 비로그인 시 `로그인`, 서버에서 실제 로그인 상태 확인 뒤 `마이페이지`.
- 신규 네이티브 앱 없음. 기존 HTML/CSS/JS + Stage4F 모바일 프레임을 사용.

## 화면/행동 정책

1. 모든 화면의 상단: Sabrina 영문 POPO 로고를 유지하고 오른쪽에 달 모양 `로그인` 버튼. 기존 `서비스 안내`는 계정 안내창에서 접근.
2. 440px 모바일 캔버스: PC에서도 중앙에 표시. 320~440px 휴대폰은 전체 너비 활용.
3. 기존 하단 `.mobile-nav`는 **시각적으로 감춤**. DOM/기존 이벤트는 보존해 `app.js` 라우터를 그대로 사용.
4. 화면 우측 하단 작은 `✦ 메뉴` 버튼을 고정 배치. 터치하면 `홈 · 내 사주 · 오행 · 운세 · AI 상담 · ↑ 맨 위로`가 열림. 메뉴는 화면 크기에 맞춰 중앙 모바일 캔버스 오른쪽 모서리에 정렬.
5. 메뉴 바깥 클릭/Escape/메뉴 선택 시 닫힘. 키보드 포커스 및 ARIA 속성 제공. 입력창에 포커스가 잡히면 작은 메뉴도 일시 숨김.
6. 로그인 전: 계정 안내 대화상자에 **로그인 기능 준비 중** 표시. 로그인 성공을 가장하지 않음.
7. 로그인 후 화면 상태: 미래의 실제 인증 연동이 서버에서 세션을 검증한 다음 `PopoAccountNav.updateFromVerifiedSession(session)`을 호출하도록 접점만 마련. **이 메서드는 UI 라벨 변경용이며 서버 인증을 대신하지 않음.** 개인정보나 사주 기록을 클라이언트 메서드로 조회할 수 없음.
8. **출생정보/AI API/Function Calling 기능은 변경하지 않음.**

## 패치 적용 호환성

- 현재 GitHub baseline `3164ae5` (Stage4A). 사용자가 로컬에 적용한 Stage4C/D, 4E.2를 기준으로 함.
- Stage4F가 이미 적용된 경우: 파일 SHA를 검사하고 그대로 유지, Stage4G 파일만 추가.
- Stage4F가 아직 적용되지 않은 경우: 본 ZIP에 동봉한 Stage4F 파일을 **신규 설치**한 뒤 Stage4G를 추가.
- 불완전하게 적용된 Stage4F, 기존 파일명이 충돌, 뜻밖의 Git HEAD 등은 변경 전 중단.
- HTML 로딩 태그 1회 추가, 기존 코드는 최대한 그대로 유지. 실패 시 index 원본 복원 및 이번에 만든 파일 삭제.
- 자동 Git commit/push 없음. 실제 Windows 모바일/PC QA 확인 이후 반영.

## 필수 후속 작업

- 실제 로그인 기능: Google/Kakao/이메일 중 인증 공급자 선택 → HTTPS 백엔드 세션 발급·갱신·로그아웃 → 서버 인증/권한 검사 → 마이페이지 기록 저장·삭제 정책 설계. **미구현**.
- 공개 휴대폰에서 실제 개인화 사주/AI를 실행하려면 검증된 계산 엔진 및 HTTPS API 배포, 접근 제어, 사용자 동의, 개인정보 보안 점검 필요. 본 단계는 웹 UI와 탐색 동작 구현.
- 320/360/390/440/768/1440px의 실제 디바이스 및 Chrome/Safari 터치 QA는 로컬 테스트 후 추가 확인.

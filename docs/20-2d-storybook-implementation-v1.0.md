# 포포(POPO) 2D 그림책 UI — 메인·오행 리디자인 v1.0

> **문서 상태:** 코드 패치 및 정적/단위 점검 완료 · 공개 웹 배포와 사용자 테스트 전  
> **작성:** 2026-10-30 · **적용 대상:** `momoorr/POPO`의 HTML·CSS·JavaScript 목업  
> **관련 기획:** [POPO 프로젝트 계획서](16-project-plan.md), [화면설계서 v0.8](17-ux-screen-spec-v0.8.md)

## 1. 목적과 범위

POPO를 웹 개발 역량 자체가 아니라 **서비스기획 포트폴리오**로 보여주기 위해, 기존 화면·동작을 유지한 채 사용자가 쉽게 이해할 수 있는 2D 인터랙티브 화면을 제작한다.

이번 작업의 범위는 **메인 랜딩의 그림책 감성 강화**와 **오행(목·화·토·금·수) 개념 탐색 화면 신설**이다. 사주 계산·AI 응답·궁합 계산은 별도로 검증해야 하며, 이 패치에서 실제 계산 기능이 생기는 것은 아니다.

### 변경 전 문제/가설 → 설계 판단

| 가설 또는 발견 | 설계 판단 | 검증할 내용 |
|---|---|---|
| 메인의 달토끼가 브랜드 인지에 도움이 될 수 있다 | 승인된 포포 이미지는 유지하고 주변에 느린 별빛·구름 모션만 추가 | 첫 방문자가 캐릭터와 서비스 목적을 쉽게 이해하는가 |
| 전문 용어 '오행'을 텍스트만으로 이해하기 어려울 수 있다 | 하나의 화면에서 오행별 색·풍경·쉬운 뜻을 직접 전환 | 오행의 기본 뜻을 찾아 자기 말로 설명하는가 |
| 기능이 많을수록 탐색 동선이 복잡해질 수 있다 | 홈 안내 카드와 명식 화면에서 오행 화면에 진입, 최상위 메뉴는 그대로 유지 | 사용자가 힌트 없이 오행 화면을 찾을 수 있는가 |
| 대규모 기술 스택 변경은 개발 지연·기능 회귀 위험이 있다 | 기존 `data-view` 전환 및 JS 이벤트 구조 재사용 | 궁합·명리 용어·AI 목업의 기존 동작 유지 여부 |

위 내용은 **기획 가설 및 설계 결정**이다. 개선 효과를 측정했다고 주장하지 않는다.

## 2. 사용자의 목표 흐름

`홈 → 오행 산책 시작하기 → 목/화/토/금/수 선택 → 해당 풍경과 일반 개념 확인 → 오행 용어 설명 → 내 사주로 돌아가기`

또는 `내 사주 → 오행의 다섯 풍경 → 오행 선택`으로 진입한다. 사용자 선택은 실제 명식 계산 결과에 영향을 주지 않는다.

## 3. 구현 변경 파일

| 파일 | 변경 내용 | 변경 전략 |
|---|---|---|
| `prototype/index.html` | 홈 구름 장식/오행 진입 카드, 내 사주 오행 CTA, `data-panel="elements"` 화면 추가 | 기존 화면·메뉴·폼 유지 |
| `prototype/styles.css` | 파스텔 토큰, 2D 랜딩 장식과 부드러운 모션, 오행 탭·풍경 전환·모바일 레이아웃 | 기존 규칙 뒤에 필요한 스타일 추가 |
| `prototype/app.js` | `elements` 라우팅, 오행 테마 데이터, 클릭·키보드 전환 | 기존 궁합·풀이·상담 목업 유지 |
| `prototype/design-tokens.json` | 그림책형 색상과 움직임 정책 기록 | 디자인 기준 개정 |
| `prototype/assets/scene-*.svg` (5개) | 숲·불빛·언덕·은빛 결정·물결의 독자 제작 2D 풍경 | 기존 달토끼 이미지 재사용 |

앞서 업로드에 실패한 **v0.9.3 UX 수정**(심화 버튼 문구 변경, 궁합 관계별 설명 차별화, 날짜 필드별 오류 표시)도 새 `index.html`/`app.js`/`styles.css`에 포함한다. GitHub에서 별도 v0.9.3을 먼저 적용할 필요는 없다.

## 4. 오행 화면 정보 정책

- 5개 버튼: 목(木), 화(火), 토(土), 금(金), 수(水)
- 변경 요소: 2D 풍경, 선택 버튼 상태, 카드 제목, 일반적인 전통 상징 설명
- 움직임: 풍경 간 약 600ms 전환, 달토끼의 느린 부유 모션, 별빛과 구름의 은은한 움직임
- 데이터 출처: **프로토타입에 포함된 일반 개념 문구**, 실제 출생 정보 및 계산값과 무관
- 불확실성 안내: 화면 상단과 설명 카드에 `일반 개념 시연 / 개인 명식 결과 아님` 명시
- 접근성: 네이티브 버튼, 화살표·Home·End 키보드 선택, `aria-selected`, 포커스 표시, `prefers-reduced-motion` 대응

오행의 전통적 설명을 성격 진단이나 미래 예측으로 단정하지 않는다. 추후 명식 계산 엔진 검증 후 개인화 결과와 연결한다.

## 5. 이번 패치에서 제외한 기능

사주 명식 계산, 음력/절기 처리, 실제 오행 구성·비율, 대운·세운 계산, AI 모델 호출, 궁합 산식은 **이번 구현 범위에 포함하지 않는다**. 기존 화면의 시연용 표시를 유지한다.

## 6. 검증 계획 및 완료 기준

**정적·단위 점검 수행:** JavaScript 구문 검사, 화면 ID 중복·연결 검사, 5개 SVG 유효성 검사, 오행 선택 상태와 키보드 이동의 격리 단위 검증.

**공개 웹 수동 QA 필요:** 360px·390px 모바일과 데스크톱에서 홈/오행 레이아웃을 확인하고, 빠른 연속 클릭, 탭 키·화살표 키, 모션 줄이기, 기존 궁합·용어 팝업·상담 목업을 실행한다. 별도 [QA 체크리스트](../qa/06-2d-storybook-qa-v1.0.md)에 기록한다.

**완료 판정:** (1) 사용자가 새 화면에 접근하고 5개 테마를 전환할 수 있음 (2) 기존 화면으로 돌아갈 수 있음 (3) 모든 화면에서 시연용 상태 명확 (4) 기존 기능 회귀 없음 (5) 모바일·키보드 접근성 수동 확인. 현재 공개 배포 및 실제 사용자 검증은 아직 완료로 표기하지 않는다.

## 7. 변경 기록

- **v1.0 (2026-10-30):** 기존 POPO v0.9.2 소스에 이전 v0.9.3 UX 개선안 병합, 메인 그림책형 장식·오행 5종 인터랙션 추가.
- 주요 의사결정: **기존 프런트엔드 전면 개편 금지**, 별도 프레임워크 도입 없음, 승인된 달토끼 원본 유지, 일반 오행 개념과 개인화 해석 명확히 분리.

# 계산·콘텐츠·AI 정책 초안

## 출처와 진실성 구분

| 구분 | 예시 | 시스템 책임 |
|---|---|---|
| 계산된 명식 | 년·월·일·시주 | 검증된 역법 엔진 |
| 전통적 해석 | 오행과 십성에 대한 관점 | 규칙/판본/학파 표시 |
| AI 문장 생성 | 질문에 맞춘 요약·설명 | 계산값 변경 금지 |
| 문화 콘텐츠 | 토정비결·타로 | 독립 계산과 면책 표시 |
| 현실적 사실 | 건강·직업·학업 관련 근거 | 운세와 명확히 구분 |

## 특히 토정비결

한국민족문화대백과사전의 ‘토정비결’ 항목은 태세·월건·일진 등을 사용하고, 생시를 제외한 연월일로 상중하 괘를 만들어 음력 12개월 풀이를 제공한다고 설명한다. **사주 원국·세운과 동일한 계산이 아니다.** 판본·괘수 계산 변형이 존재할 수 있으므로 정확한 알고리즘, 원문/번역 이용권한, 월별 대응 달력을 고정해야 한다.

- **전용 서비스 단위:** `tojeong_engine_version`, `reference_edition`, `lunar_year`, `gua_code`.
- **검증 필수:** 상중하괘 공식·예제·경계 연도·윤달 처리·음력 29/30일.
- **출시 보류:** 공식이나 콘텐츠 출처가 검증되지 않은 경우 '결과'를 임의 생성하지 않는다.

## AI 응답 규칙

```text
1. 질문에 직접 답변
2. 관련 전통적 해석을 간단히 설명
3. 사용한 명식/해석 요소 명시
4. 사실/해석/불확실성 구분
5. 생활에서 선택할 수 있는 현실적 점검 사항
```

다음을 금지하거나 제한한다.
- AI 단독 명식·괘수 산출
- 건강 진단/수명·재회 시점·타인 생각·시험 합격·투자 수익의 확정적 예언
- 불안 유발·공포 마케팅 또는 유료 결제 압박
- 잘못된 명식/계산을 확인하지 않은 채 계속 설명
- 사용자 기록이 저장되지 않았는데 저장되어 있다고 주장

## 개인정보 기본 원칙

- 계정 없이 기본 체험. 데이터 보관·회원 전환 정책 미결정.
- 출생일시/출생지역/상담 원문은 필요한 범위만 수집.
- 이벤트 로그에 민감한 원문을 남기지 않는다.
- 공유 카드에는 개인 생년월일 등 기본 비노출.
- 타인 기록 접근 불가, 서버 API 키 보호, 삭제 정책 확정.

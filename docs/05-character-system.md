# 일주 캐릭터 시스템 | 60갑자 × 나다운 표현

**상태:** v0.4 제안. 실제 삽화 60종 제작 및 검수는 미완료.

## 사용자 가치

문자가 중심인 명식을 귀여운 시각적 대상으로 만들되, ‘내 사주만의 캐릭터’라는 표현이 사실보다 과장되지 않도록 한다. 정확히는 **같은 일주를 가진 사용자는 같은 기본 캐릭터**를 받는다. `나만의` 느낌은 사용자가 고르는 액세서리·배경·표정 등 개인화 선택으로 제공한다.

## 결정적 매핑

- 10천간 데이터 코드는 甲乙丙丁戊己庚辛壬癸
- 12지지: 子丑寅卯辰巳午未申酉戌亥
- 육십갑자: 첫 날 `甲子`에서 순서대로 천간과 지지를 한 칸씩 전진시키며 60번. 60개만 유효하고 120조합을 만들지 않는다.
- 저장 필드: `day_pillar_index` (0~59), `character_id` (`c01`~`c60`), `name`, `symbol`, `asset_version`, `illustration_asset`, `text_review_status`.
- 엔진의 일주 계산이 먼저 검증되어야 한다. 사용자 입력만으로 일주를 임의 구성하지 않는다.

## 아트 디렉션

**별숲의 수호자들**. 동글한 실루엣, 작은 눈·볼터치, 2~3색 악센트, 절제된 별 조각. 명리학 요소는 `정해진 캐릭터에 사실처럼 성격 부여`하기보다 전통적 상징에서 영감을 얻은 시각적 디자인으로 사용한다.

### 베이스 모티프 제안

| 테마 | 컬러 | 표현 모티프(디자인 제안) |
|---|---|---|
| 목(木) | 새싹 민트 | 잎사귀·씨앗 |
| 화(火) | 코랄 핑크 | 반짝이는 불씨 |
| 토(土) | 머스터드 골드 | 별의 정원·돌 |
| 금(金) | 실버 라일락 | 작은 종·빛 조각 |
| 수(水) | 아쿠아 블루 | 물방울·구름 |

이 테마는 **그래픽 규칙**이며 과학적 개인성격 판정이 아니다. 60종 일주별 콘셉트 표는 해석 규칙과 함께 검토 후 완성한다.

## 60 캐릭터 제작 전략

1. P1 초기: 5개 시각 모티프와 공통 리깅/레이어 구조를 검증한다.
2. 10천간 × 12지지의 올바른 유효 조합 60개로 `character_id`를 구성한다.
3. 장식 6종(별모자, 리본, 꽃, 목도리, 반짝이, 구름)을 사용자가 선택한다.
4. 일주 명칭은 명리 해석 검수 이후 공개한다.
5. 최종 QA에서 ID-명식 매핑 60건과 시각 유사도·저작권 독창성을 점검한다.

## 구현 수용 기준

- `day_pillar_id`가 유효하면 언제나 같은 기본 캐릭터 ID.
- 60개 ID의 중복·누락이 없다.
- 출생정보 변경으로 일주가 바뀌면 캐릭터 매핑도 바뀐다.
- 장식 변경은 명식 계산·해석에 영향을 주지 않는다.
- 타 서비스의 이미지를 복제하지 않고 직접 제작·사용권한 확보.

## 공개 데이터 주의

실명·생년월일·개인 상담 내용이 공유용 캐릭터 카드에 자동 포함되지 않도록 한다.

# 포포(POPO) 사주 계산 엔진 후보 연결 v1.3 — 기술검증 문서

- 작성: 2026-10-30 / 대상: `prototype/` 정적 웹 UI
- 상태: **계산 후보 미리보기 (정확성 교차 검증 전)**
- 사용자 목표: `출생 정보 → 검증된 명식 → 오행 이해 → AI 질문`
- 본 버전 결과는 **정식 개인 명식, 궁합, AI 해석 데이터가 아님**.

## 1. 왜 기존 명식을 그대로 바꾸지 않았는가

기존 화면의 년·월·일·시주는 가상 데이터다. 역법 정책(절기, 자시 날짜, 한국 출생 시각, 음력 윤달)을 검증하지 않고 가상 명식을 실제 결과로 교체하면 잘못된 정보를 제공할 수 있다. 따라서 기존 명식과 오행 그림책은 그대로 두고 **독립된 실험 결과**만 추가했다.

## 2. 계산 엔진 후보

| 항목 | 내용 |
|---|---|
| 후보 | `lunar-javascript@1.7.7`, MIT, 6tail 프로젝트 |
| 적용 | 브라우저에 라이브러리 파일을 로컬로 포함해 실행(인터넷 CDN 의존 없이 배포) |
| 제공 가능 API | `Solar.fromYmdHms(...).getLunar().getEightChar()`의 네 기둥 |
| 연동 상태 | 후보 어댑터, 버전 고정, 브라우저에서 직접 테스트 필요 |
| 한국 기준 확정 여부 | **미확정.** 중국/한국 절기 경계·시간 보정·정밀 시각 교차 검증 필요 |
| 정부 자료 | 한국천문연구원/공공데이터포털 음양력 데이터는 독립 참고/검증 자료 후보. API만으로 사주 전체가 자동 검증되지 않음 |

출처: [원본 저장소](https://github.com/6tail/lunar-javascript), [npm](https://www.npmjs.com/package/lunar-javascript), [공식 API](https://6tail.cn/calendar/api.html).

## 3. 시험 입력 제한(확정 정책 아님)

- **양력만**; 음력·윤달은 아직 지원하지 않음.
- 1990–2040년 중 올바른 날짜, 서울/부산/대전 입력(한국 표준시 가정).
- 출생 시간이 있어야 하며 00시·23시는 제외(자시/날짜 변경 경계).
- 매월 3–9일은 절입 경계 오차 검증을 위해 기술 시험에서 제외.
- 지역별 경도 보정·진태양시·역사적 지역 시간·천문학적 교차 검증 미반영.
- 출력값은 **엔진이 반환한 시험값**이며 올바른 한국 사주라는 증거가 아님.

이 범위는 사용자의 정식 서비스 이용 범위가 아니라, 개발 중 잘못된 확정 결과를 줄이기 위한 **임시 보수적 게이트**다.

## 4. 오행 연결 데이터 정책

`甲乙→목`, `丙丁→화`, `戊己→토`, `庚辛→금`, `壬癸→수`.

지지는 대표 오행만 배정한다: `寅卯→목`, `巳午→화`, `辰戌丑未→토`, `申酉→금`, `亥子→수`.

년·월·일·시 4개 기둥의 천간과 지지 8글자 각각을 1개씩 세므로 **합계 8**이 된다. 이 수치는 **강약·월령·용신·지장간 비율을 뜻하지 않는다.** 합계가 다르면 오류로 중단한다.

## 5. 데이터 흐름과 보안

1. 사용자가 출생 정보 입력 폼에서 `엔진 후보 시험값 보기`를 선택한다.
2. 입력 검증을 수행한다. 지원 범위 밖이면 왜 안 되는지 표시하고 결과 생성 중단.
3. 로컬 `lunar-javascript`를 호출해 네 기둥을 산출한다.
4. 순수 함수에서 8글자 표면 오행의 **개수**만 계산한다.
5. 모달에 `검증 전 엔진 후보 산출값`을 표시하고, 오행 설명 화면에 숫자 미리보기만 연결한다.
6. **기존 `chart`의 가상 사주, AI 상담, 궁합 점수는 변경하지 않는다.**

입력값은 서버로 전송하지 않으며, `localStorage`·쿠키·DB에 보관하지 않는다. 다만 실제 서비스 배포 전에는 해당 라이브러리의 공급망과 개인정보 정책도 검토해야 한다. 개발 중에는 가상 날짜로 테스트한다.

## 6. 수용 기준

- 오류 날짜, 음력, 자시 경계, 출생 시간 미상, 지원 지역 밖에서는 결과를 생성하지 않음.
- 라이브러리 미로드·호출 실패 시 설명 가능한 오류 표시.
- 유효한 가상 입력에 대해 시험값 네 기둥 + 표면 8글자 오행 합계 8 표시.
- 기존 사주 예시 화면/오행 그림책/궁합/AI 목업 동작을 유지.
- 포트폴리오에서 '엔진 후보 연결'과 '공인 검증된 사주 계산'을 혼동하지 않음.

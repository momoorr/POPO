# POPO Stage 4C — 다정한 대화체와 영어 로고 적용

- 기준: `momoorr/POPO` `3164ae5` + 사용자가 로컬 적용한 Stage 4B (아직 GitHub 미반영).
- 요청: 포포 화면 전체의 문구와 실제 AI 답변 말투를 자연스럽고 친근하게 통일하고, 상단 브랜드를 별 장식이 있는 영어 `popo` 로고로 변경.
- 사용자 참고 이미지: `Sabrina / pop up store` 손그림 느낌. 원본 사진 속 폰트의 정확한 서체명과 라이선스는 확인되지 않았으므로 **원본 폰트를 추출하거나 복제하지 않음**. 오픈 소스 Google Fonts `Henny Penny`와 별 장식으로 재해석.
- 범위: 로고/대표 문구/입력/채팅/미검증 안내 + 서버 AI 시스템 지시. 별도의 기능, 모델, 사주 결과 신뢰 상태 변경 없음.

## 사용자 경험 의사결정

1. 홈과 AI 상담 사이에서 친근한 대화체를 유지한다. 유치한 과장과 과도한 이모티콘은 피한다.
2. 서버의 `SYSTEM` 지시를 따뜻한 자연스러운 **반말(해체)**로 통일한다. 일반 질문은 2~4문장 내외로 답하도록 유도하고, 길어 출력 예산에 걸린 답은 부분 문장을 그대로 보여주지 않는다.
3. **검증되지 않은 개인 사주를 생성하지 않는다.** `get_saju_chart` 호출 의무와 미검증 차단은 유지한다.
4. 공개 GitHub Pages 채팅은 계속 시연용. 로컬 `127.0.0.1:8000` API 연동은 `localhost`/`127.0.0.1`에서만 활성화한다. 사용자의 API 키는 서버 환경변수에서만 관리한다.
5. 상단 로고는 영문 `popo`와 장식 별로 표시하고, 스크린리더용 `aria-label`에 한글 브랜드명을 함께 남긴다.
6. Google Fonts를 사용할 수 없으면 브라우저 기본 필기체로 대체한다. 글꼴 파일은 패키지에 포함하지 않는다.

## 실제 변경 파일

- `prototype/index.html`: 영문 브랜드/별 장식, 사용자 안내 문구와 상담/출생 입력 텍스트, CSS/JS 로딩.
- `prototype/app.js`: 공개 목업 답변과 일부 동적 안내 문구 다듬기.
- `prototype/chat-live-local.js`: 실제 로컬 채팅 인사/버튼/오류 안내 다듬기. 기존 13개 동작 계약 보존.
- `prototype/popo-friendly.css`: 영문 로고와 채팅 문단 스타일.
- `prototype/popo-friendly-ui.js`: 로컬 채팅 중이라는 상태 안내, 공개 모드와 구분.
- `backend/main.py`: 실제 LLM의 말투 지시와 응답 길이 조절. 미완료 응답 방어.
- `tests/local-live-agent.test.cjs`, `tests/popo-friendly-ui.test.cjs`, QA/기획 문서: 메시지 변경에 맞춘 테스트.

## 검증 구분

- 코드 문법 및 오프라인 모의 호출: 설치 패키지에서 실행.
- 실제 사용자 Windows/Chrome 화면과 API 응답 말투: **사용자가 Stage 4C 적용 후 확인 필요.** 서버는 코드 변경 후 재시작 필수.
- 로고는 참고 사진과 동일한 원본 글꼴이 아니라 장식적 유사 스타일임.
- GitHub에 자동 푸시하지 않는다. Stage 4B를 포함한 로컬 수정사항을 함께 검토한 다음 별도 커밋한다.

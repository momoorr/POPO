# POPO Stage 5C.3 — 사주 보관함 간격과 버튼 배치

## 요청과 범위

사용자는 Stage 5C.2의 실제 추가·수정·삭제가 정상이라고 확인했다. 이번에는 카드 아래의 분리된 수정/삭제 영역을 없애고, 정보 오른쪽에 버튼 두 개를 세로로 배치한다. 카드·목록·패널 간격을 줄이고, 중복인 하단 `완료 · 마이페이지로` 버튼은 DOM에서 제거한다. 오른쪽 상단 X와 Escape, 저장 성공 후 마이페이지 복귀는 유지한다.

## 구현

- `prototype/popo-profile-crud.css`: 보관함 카드만 두 열로 배치. 왼쪽은 사진/이름/관계/출생정보, 오른쪽은 44px 이상의 수정/삭제 버튼. 계정 화면 자체의 카드나 시간 선택창은 변경하지 않는다.
- `prototype/popo-profile-crud.js`: 완료 버튼 생성/참조/이벤트만 제거. 저장, 삭제, 세션 검증, 시간 선택 로직은 변경하지 않는다.
- `prototype/index.html`: 두 파일의 캐시 버전만 `5c2`에서 `5c3`으로 변경.
- API 요청 계약, 테이블, 접근 정책, 키, 폰트, 동물 배정 규칙은 변경하지 않는다.

## 설치

이전 5C.2 소스 해시 및 관련 읽기 전용 의존 코드를 확인한다. 로컬 수정이 발견되면 덮어쓰지 않는다. 실제 변경 파일만 별도 폴더에 백업하고, 실패 시 원복한다. Git 인덱스와 커밋을 수정하지 않는다. 인스톨러는 네트워크를 사용하지 않는다.

## 검증 구분

오프라인 브라우저 테스트는 모의 인증/DB를 사용한다. 기존 저장 기능의 실사용 성공은 사용자의 5C.2 보고이며, 이번 5C.3의 Windows 설치와 실제 계정 동작은 적용 후 별도 확인한다. 글꼴 파일을 패키지에 포함하지 않는다.

# 포포 PRD v0.4 — 추가 변경 제안서

- 기준: 사용자가 공유한 **PRD v0.3 Final**
- **기존 확정 의사결정 D-01~D-04 및 P0 기능을 변경하지 않음**
- 이번 문서는 운세/토정비결/캐릭터/UX에 관한 **신규 제안**이며 최종 합의 전 개발 확정사항은 아님

## 1. 요구사항 변경 배경

운세 종류 확대 요청: 인생 총운, 대운, 세운, 올해 총운, 연애, 금전, 인간관계, 직업, 학업, 오늘의 운세, 재회, 건강, 토정비결. 단순 카테고리 추가는 중복과 탐색 비용을 높이므로 ‘**시간축 × 주제축 × 설명 깊이**’로 재구성한다.

### 새로운 4개 상위 그룹

1. **내 사주(원국·총운)** — 년·월·일·시주 기반의 전통 해석/오행/십성
2. **운의 흐름** — 대운, 세운, 올해 총운, 오늘의 운세
3. **관심 주제** — 연애, 금전, 인간관계, 직업, 학업, 재회, 건강 관련 해석
4. **새해 특집** — 토정비결(사주 계산과 독립적인 괘/월별 해석)

### 중복 해결

- `세운`: 1년의 전통 계산·해석 요소(전문 레이어)
- `올해 총운`: **같은 세운 데이터를 요약해서** 초심자에게 보여주는 쉬운 레이어. 별도 계산 엔진이나 상충한 점괘로 만들지 않는다.
- `인생 총운`: 현재 원국의 전반적 성향 및 시기별 설명을 종합해 읽을 수 있는 요약. 확정적 평생 예언 금지.
- `토정비결`: 사주 명식 연운과 별도. 태세·월건·일진 기반의 괘 및 음력 월별 풀이. 계산 규칙·판본·저작권 검토 후 출시.

## 3. 추가 기능 요구사항

### FR-V04-001 — 전체 운세 목록

- 시스템은 메뉴를 상위 그룹 4개와 개별 카드로 표시한다.
- 처음에는 ‘내 사주/운의 흐름/관심 주제/새해 특집’만 보여주고 세부 카테고리를 펼칠 수 있다.
- 미구현 카테고리는 활성화하지 않으며 출시된 것처럼 보이는 더미 CTA 금지.

### FR-V04-002 — 인생 총운 카드

- 원국 기반 종합 해석의 핵심 요약과 사용된 명식 요소를 분리해서 보여준다.
- 대운/세운 등이 미검증이면 해당 시기 예측을 임의로 합성하지 않는다.
- `전통적 해석이며 미래를 보장하지 않습니다` 안내.

### FR-V04-003 — 세운/올해 총운 2단계 노출

- 같은 연도·정책 버전과 세운 계산 결과를 참조한다.
- 쉬운 요약과 전문가의 연운 근거는 같은 데이터 ID를 사용한다.
- 기준 연도와 한국 시간대 등을 표시한다.

### FR-V04-004 — 토정비결 전용 계산

- 입력: 선택 연도/양음력·윤달 포함 출생일(필요한 경우); 생시는 일반적으로 계산에 사용하지 않음.
- 결과: 선정된 판본·계산법에 따른 괘 ID, 연간 전체 풀이, 음력 1~12월 풀이.
- 각 월에는 음력 기준임을 표시하고 양력 대응 날짜가 필요하면 변환 규칙/윤달을 검증한다.
- 다른 사주 연운과 다른 결과가 나와도 각기 다른 방식임을 설명한다.
- 원문/현대어 번역의 이용권한 및 출처를 확인한다.

### FR-V04-005 — 60갑자 캐릭터

- `day_pillar_id (1~60)` → `character_id` 결정적 매핑.
- 각 캐릭터는 기본 이름/일주 코드/상징/설명/일러스트 리소스/버전 포함.
- 동일 일주 사용자에게 같은 기본 캐릭터가 주어짐을 투명하게 안내.
- 원하는 경우 장식·배경·표정 변형으로 표현 다양성 확장. 개인화가 점술상 정밀한 성격 판정인 것처럼 보이지 않도록 함.
- 시간 미상 등으로 일주 산출이 검증되지 않을 때 임의 캐릭터 금지.

### FR-V04-006 — 안전한 관심 주제

- **재회**: 상대방의 마음·재회 날짜를 확정 예측하지 않으며 관계를 돌아볼 질문을 제공.
- **건강**: 질환·수명·약물·치료 결정에 사주를 사용하지 않는다. ‘마음·생활 리듬 돌보기’ 등의 문화적 웰빙 콘텐츠로 제한.
- 직업·학업·재물은 실제 합격/투자 수익을 보장하는 표현 금지.

### FR-V04-007 — UI 접근성과 반짝임

- 별빛과 오라(halo)는 장식 영역에만 적용하고 핵심 내용·입력·버튼 배경과 겹치지 않는다.
- 다크 네이비 배경 + 아이보리 콘텐츠 카드 + 1차 보라 포인트.
- CTA는 화면당 1개 중심, 보조 버튼 1~2개.
- 장식 애니메이션에 움직임 줄이기 지원; WCAG 대비 기준 검증.

## 4. 수용 기준 (추가)

- AC-01: 운세 12개 이상을 하나의 긴 스크롤에 무작위 나열하지 않는다.
- AC-02: 올해 총운과 세운은 같은 연도/계산 데이터 ID를 공유한다.
- AC-03: 토정비결은 사주 연운과 명확히 구분된다.
- AC-04: 캐릭터 ID 매핑이 60개 일주 전 범위에서 중복 없이 동작한다.
- AC-05: 건강·재회에서 타인 마음·의학적 예언을 단정하는 응답이 나타나지 않는다.
- AC-06: 인터랙티브 목업은 가상 데이터 표식을 항상 노출한다.

## 5. 범위 관리

P0 기능이 실제로 연결되기 전까지 추가 콘텐츠를 ‘완료’로 표기하지 않는다. 이 PRD의 v0.4 신규 항목은 기업 포트폴리오에서 **아이디어와 제안, 구현된 것과 검증한 것을 명확히 분리**한다.

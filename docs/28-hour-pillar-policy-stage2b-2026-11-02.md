# POPO Stage 2B — 시주(時柱) 시두법 대조 계획

- 작성: 2026-11-02
- 대상: `lunar-javascript@1.7.7` 기반 `prototype/calc-core.js`의 **미검증 계산 후보**
- 배포 목적: 기존 Stage 2의 외부 날짜 12건과 시두법을 결합한 규칙 검증
- 기존 화면·AI 백엔드·만세력 계산 코드는 수정하지 않음

## 1. 이 검사가 필요한 이유

Stage 2의 브라우저 26/26 PASS는 외부 자료의 **연주·월주·일주**를 대조하고 시주는 두 글자 형식만 확인했다. 이것만으로 4주 8자의 정확성을 확정할 수 없다.

## 2. 독립 규칙: 시두법

한국민족문화대백과사전 '사주'에 기록된 시두법에 따라, 일간별 자시 시작 천간은 다음과 같다.

| 일간 | 자시 시작 천간 |
|---|---|
| 甲·己 | 甲 |
| 乙·庚 | 丙 |
| 丙·辛 | 戊 |
| 丁·壬 | 庚 |
| 戊·癸 | 壬 |

자시 이후 시지를 순서대로 진행하면서 천간도 한 칸씩 진행한다. 날짜별 **일간은 외부 날짜 자료의 고정 fixture**에서 취하고 후보 라이브러리의 일간을 참조하지 않는다.

**문헌:** https://encykorea.aks.ac.kr/Article/E0025957

## 3. 이번 시험의 명시적인 시각 정책

- 기준: 한국 표준시 KST로 기록된 시계를 **보정 없이** 2시간 간격의 시지에 대응한다는 임시 시험 가정.
- 01:00~22:59 (축시~해시) 구간만 테스트한다. 00시대·23시대는 기존 계산 후보 정책대로 차단하고, 경계 날짜 변경 규칙은 결정하지 않는다.
- 실제 출생 지역의 경도 보정, 균시차, 자시 날짜 변경은 **검증하지 않는다**. 시두법 대조가 통과해도 모든 한국 출생자의 최종 명식은 보증하지 않는다.

## 4. 자동 시험 구성

1. Stage 2 공개 날짜 자료의 연·월·일주 12건을 그대로 사용한다.
2. 각 날짜의 01:30·03:30·…·21:30 11개 시각 = 132건.
3. 대표 날짜 2000-01-01, 2000-02-10에 시지 변경 직전/직후 시각 12개씩 = 24건.
4. 합계 **156건**. 후보 4주와 외부 날짜 3주 및 독립 시두법 시주를 대조한다.
5. 자동 시험 페이지: `qa/hour-pillar-check.html`.

## 5. 검증 단계 및 한계

- 로컬: 순수 시두법 8개 고정 예제, 6개 잘못된 입력, 156개 결정적 **모의** 계산 후보, 의도적 시주 오답 검출 테스트.
- 웹: GitHub Pages가 실제 `prototype/vendor/lunar.min.js`, `prototype/calc-core.js`를 로딩한 브라우저 테스트. **결과는 사용자가 확인하기 전까지 미실행**.
- 남은 필수 검증: 한국천문연구원 역법 데이터 직접 대조, 절입 시각 전후, 실제 시주 정책(KST 무보정/보정 여부), 자시 및 역사적 표준시, 연도 범위 확장.
- 백엔드 `chart_service.py`의 `verified=false` 차단은 변경하지 않는다.

## 6. 포트폴리오 기록

테스트를 통과하더라도 '사주 계산 완성'이 아니라 '외부 연월일주 기준 + 전통 시두법 기준 시주 대조를 자동화하고 정책 경계를 분리함'으로 기록한다. UI와 Figma 디자인은 변경 없음.

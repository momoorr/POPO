새 기능 요청은 고객 가치, 의존성, 위험, 예상 구현 규모, 측정 지표를 비교하여 확정한다. **화면에 존재하는 항목과 실제 제공 중인 기능을 구분**한다. PRD v0.3의 기존 확정 사항은 별도 기록 없이 덮어쓰지 않는다.

## SCR-12 토정비결 화면 정의

**UI 구성 요소**: 상단 ‘새해의 토정비결’ 타이틀 → 계산법 안내 토글 → 기준 음력 생일/연도 확인 → 결과 총괘 카드 → 음력 1~12월 아코디언 → 해석 근거/판본 안내 → 관련 AI 질문.

**예외**:
- 원문/판본 또는 계산 규칙 불확실: 괘 결과 비노출
- 입력 생일이 해당 달에 없음: 오류와 수정법 표시
- 윤달 처리 정책 미정: 결과 생성 금지
- 이미 계산된 사주 세운과 상충할 때: 계산법 자체가 다르다고 설명

**수용 기준**:
- 토정비결 계산과 사주 원국 계산 서비스 함수가 명확히 구분된다.
- 기준 연도/달력/월별 정보 표시.
- 원문과 번역/창작 해설을 구분하고 출처·권한 검토.
- '결과 생성'으로 보이는 테스트 임의 텍스트 없음.

## SCR-13 운세 허브

**UI**: `내 사주`, `운의 흐름`, `관심 주제`, `새해 특집` 4개 그룹. 실제 출시된 기능은 뚜렷한 CTA, 미출시 기능은 '준비 중'으로 구분.

**예외**: 회원가입 이전 내 사주 없을 때 → 비회원 출생정보 입력 경로 제공. 출생 시간 미상·연도 정책 미결정은 해당 기능에서 별도로 안내.

**수용 기준**: 카테고리 제목만 보고 목표 콘텐츠를 찾아갈 수 있어야 하며, 복수의 서비스에서 중복 계산값을 노출하지 않는다. 실제 테스트 계획은 `research/02-usability-test-plan.md` 참조.

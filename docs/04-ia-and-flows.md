# 정보 구조 · 사용자 흐름 (v0.4 제안)

## 모바일 하단 메뉴

**홈 / 내 사주 / 운세 / AI 상담 / 전체**. 단, P0에서 미구현 메뉴는 동작하는 것처럼 노출하지 않는다. 데모의 모든 내용은 목업.

```text
HOME
 ├─ 오늘의 발견(출시 단계에 맞게)
 └─ 사주 시작
      └─ 출생정보 입력
           └─ 명식 결과
                ├─ 오행·일간·용어 설명
                ├─ 내 사주 → 인생 총운 / 심화
                ├─ 관심 주제 → 연애 / 금전 / 관계 / 직업 / 학업 / 재회 / 웰빙
                ├─ 운의 흐름 → 대운 / 세운 / 올해 / 오늘
                ├─ 새해 특집 → 토정비결(별도 계산)
                ├─ 캐릭터(60갑자 일주)
                └─ AI 질문 (선택한 카테고리·명식 연동)
```

## 핵심 플로우 A: 처음 들어온 사람

홈 → '내 사주 보기' → 입력 검증 → 명식 계산 → 첫 화면: **내 명식 + 쉬운 핵심** → '내가 궁금한 운세' 선택 → 짧은 설명 → 전문 해설 펼치기 → AI 질문

## 핵심 플로우 B: 새해 특집

운세 → '토정비결' → 연도/필요 입력 확인 → 별도 괘수 계산 → 연간 풀이 → 음력 1~12월 → ‘사주 연운과 무엇이 다른가?’ 설명

## 핵심 플로우 C: 캐릭터

명식 결과 → 일주 ID 검증 → 캐릭터 카드 → 이름·상징(전통 해석) → 내가 고를 수 있는 장식 → 저장/공유(후속 정책) → 자세히 보기

## 상태 설계

| 상태 | 사용자에게 보이는 UI | 개발 처리 |
|---|---|---|
| 로딩 | 예상치 않는 긴 기다림 대신 진행 상태 표시 | 재진입/중복 호출 방어 |
| 잘못된 생일 | 해당 필드 아래 오류와 해결법 | 계산 API 호출 금지 |
| 출생 시간 미상 | '시주는 표시하지 않음' | 시주 임의 보충 금지 |
| 명식 계산 불가능 | 계산 범위 안내 | 임의 더미 데이터 반환 금지 |
| AI 타임아웃 | 재시도/이전 메시지 보존 | 중복 결제/중복 요청 방지 |
| 토정 규칙 미확정 | '준비 중' + 원리 소개 | 괘 임의 산출 금지 |
| 캐릭터 미검증 | 기본 그림/준비 중 | 임의 일주 매핑 금지 |

## 사용자 행동 데이터(기획)

`birth_start`, `birth_submit_valid`, `chart_view`, `topic_open`, `deep_view`, `ask_ai`, `ai_followup`, `tojeong_entry`, `character_open`. 이벤트에는 출생 날짜/시간 또는 상담 질문 원문을 남기지 않는다.

# 프로토타입 사용성 테스트 설계 (실시 전)

## 성공해야 할 과제

1. 첫 화면에서 명식 확인 흐름을 시작한다.
2. 출생 시간이 기억나지 않을 때 가능한 행동을 찾는다.
3. ‘올해 총운’과 ‘세운’이 어떻게 다른지 설명할 수 있다.
4. 직업·진로 카테고리 풀이를 찾고 전문가 해설로 이동한다.
5. 선택한 카테고리에서 AI에게 후속 질문을 시작한다.
6. 토정비결이 사주 연운과 별도라는 점을 인지한다.

## 수집 항목

- 과제 완료(성공/부분/실패)
- 완료까지 걸린 시간
- 처음 멈칫한 화면과 이유
- UI 이해도/혼란 의견
- 관찰한 오류와 개선 아이디어

## 가설과 판단

- H1: 그룹 IA가 카테고리 찾기를 돕는다.
- H2: 쉬운 풀이/심화 보기 구분이 명리학 이해도를 높인다.
- H3: 'AI에게 질문'이 문맥 연속성을 전달한다.
- H4: 시안의 시각 효과가 가독성을 해치지 않는다.

## 진행/이후

참여자에게 테스트 동의/녹화 여부를 명확히 알리고, 개인정보는 익명화. 테스트 완료 후 `실제 사용자 발언 / 문제 원인 / 심각도 / 수정안 / 재검증`을 기록한다.

**현재 테스트는 미실시. 결과 수치 및 긍정 반응은 기재하지 않음.**
